## 主链

这些链路对应 XMind 最核心的层级汇总关系。

- `H -> G -> F -> E -> B`
  - 管理中心：员工档案表先支撑日度，再汇总到月度，再汇总到年度，最后进入 001 页的 `管理中心` 区块。
- `L -> K -> J -> I -> C`
  - 线上事业部：员工档案表先支撑日度，再汇总到月度，再汇总到年度，最后进入 001 页的 `线上事业部` 区块。
- `P -> O -> N -> M -> D`
  - 线下事业部：员工档案表先支撑日度，再汇总到月度，再汇总到年度，最后进入 001 页的 `线下事业部` 区块。
- `B + C + D -> A`
  - 这是为了对齐当前 001 页面做的页面级补充关系，不是 XMind 原始连线。
  - 含义是：001 页的 `集团总表` 由 `管理中心` `线上事业部` `线下事业部` 三块汇总而来。

## 现阶段可以先这么理解

- `005 员工档案表` 不是单纯展示页，而是三条业务线共同的“人员主档 / 人员快照表”。
- `006 招聘入职` 和 `006 培训管理` 更像事件源，优先打到 `004 日度`。
- `006 社保` 同时有两类输出：
  - 一类进员工档案，改参保状态和参保时间。
  - 一类进月度社保，改费用口径。
- `006 人力资源规划` 同时有两类输出：
  - 一类进员工档案，改转正 / 调岗 / 职级 / 离职状态。
  - 一类直接改离职人数相关指标，但这条线在 XMind 中只部分落到了现有页面。

## 原型和当前页面的几个异常点

- `001` 页面没有 Tabs，而是 4 个纵向表块，所以这里把中心节点拆成了 `A/B/C/D`。
- `线上 002` 的 Excel sheet 名仍是 `二级-管理中心`，但内容实际是 `线上事业部`。
- `线下 002/003/004` 的原型预览里，部分标题还残留 `线上事业部` 字样，属于模板命名残留。
- `HQ 004` 的 Excel 原型只有 `招聘及入职` 和 `培训` 两个 sheet，但当前网页已经扩成了 4 个 tab。
- `线上/线下 002` 当前网页实现是纵向区块，不是 Tabs；讨论交互时要把“区块”当成 tab 的替代定位。
