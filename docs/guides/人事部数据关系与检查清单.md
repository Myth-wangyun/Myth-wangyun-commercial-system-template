## 3. 表格依赖矩阵

| 前端表格/页面 | 直接来源 | 后端表/接口 | 下游 | 类型 |

### 3.1 当前已经代码化的“基础表 -> 员工档案”链路

已明确看到同步员工档案的业务表：

- 面试登记
- 转正审批
- 社保审批
- 停薪留职审批
- 离职审批

证据：

- `backend/app/crud/human_resources/interview_registration.py`
- `backend/app/crud/human_resources/regularization_application.py`
- `backend/app/crud/human_resources/social_insurance_application.py`
- `backend/app/crud/human_resources/unpaid_leave_application.py`
- `backend/app/crud/human_resources/resignation_approval.py`

结论：

- 这些页不能只看表单本身是否保存成功，还要检查员工档案和 scope 看板是否刷新。

### 3.2 员工档案 -> 看板链路是当前最稳定的主链

结论：

- 员工档案更新后会调用 `refresh_scope_dashboard_chain`。
- 这会刷新：
  - `employee_archive_snapshots`
  - daily aggregates
  - monthly aggregates
  - yearly aggregates

证据：

- `backend/app/api/v1/endpoints/human_resources/dashboard.py`
- `backend/app/api/v1/endpoints/human_resources/employee_archive.py`
- `backend/app/crud/human_resources/dashboard.py`
- `backend/app/models/human_resources/hr_dashboard.py`

### 3.3 看板的事实表来源

可直接确认会刷新看板链的事实表或事实接口包括：

- 员工档案
- 手填招聘日事实
- 薪酬福利事实
- 绩效事实
- 多个基础申请/审批表

证据：

- `frontend/services/humanresources/dashboardDaily.ts`
- `backend/app/api/v1/endpoints/human_resources/dashboard.py`
- `backend/app/api/v1/endpoints/human_resources/recruitment_request.py`
- `backend/app/api/v1/endpoints/human_resources/training_application.py`
- `backend/app/api/v1/endpoints/human_resources/promotion_application.py`
- `backend/app/api/v1/endpoints/human_resources/transfer_application.py`

### 3.4 不能误判的边界

- 基础模块里的所有表都属于业务源表，但并不是每张表都已经代码化为“自动改员工档案”。
- 当前能稳定证实的是：
  - 一部分审批表会同步档案
  - 大部分基础表保存后会刷新看板链
  - 员工档案本身是看板最直接、最稳定的上游

## 4. 建议录入顺序

1. 先录基础模块：
   - 招聘入职
   - 培训管理
   - 人力资源规划
   - 社保
2. 再核对员工档案：
   - HQ
   - online
   - offline
3. 再看对应 scope 的日度/月度/年度看板。
4. 最后再看集团级：
   - `/humanresources/core/personal-info-dashboard`
   - `/humanresources/core/annual-comprehensive-dashboard`

## 5. 每类功能怎么检查

### 5.1 基础模块

1. 在基础模块某个 Tab 新增或审批一条记录。
2. 确认列表页刷新成功。
3. 如果该表属于“已接档案同步”的链路，再去员工档案页确认字段变化。

### 5.2 员工档案

1. 打开 HQ、online、offline 任一员工档案页。
2. 修改可编辑字段后保存。
3. 刷新当前 scope 的日/月/年看板，确认统计结果变化。

### 5.3 看板

1. 打开 daily/monthly/annual 看板。
2. 切 scope、年份、月份。
3. 核对接口返回是否来自 `/human-resources/dashboard/*`。
4. 再打开集团级 000 和 001 页面，确认高层看板口径同步。
