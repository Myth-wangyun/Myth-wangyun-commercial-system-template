### 3.1 班级列表是多个功能的共同上游

- 配置中心班级同步到 `teaching_quality."班级列表"`。
- 下游直接依赖至少包括：
  - 班级就业信息
  - 班档案表
  - 升学计划相关班级选择
  - 核心数据里的班级数量口径

证据：

- `backend/app/api/v1/endpoints/config_master.py`
- `backend/app/services/class_sync_service.py`
- `backend/app/teaching_quality/TQclass_list_db.py`
- `backend/app/teaching_quality/TQclass_file_record_db.py`
- `backend/app/teaching_quality/TQcampus_core_data_summary_api.py`

### 3.2 就业链路

结论：

- 原始就业数据在 `QT班就业信息表`。
- `就业明星表`、`班主任就业汇总表`、部分班级就业汇总都是从 QT 表和班级列表派生，不在结果页直接维护底表。
- 学术部当前多个就业页直接消费这套教质数据。

证据：

- `frontend/services/teaching-quality/TQemploymentStar.ts`
- `frontend/services/teaching-quality/TQteacherEmploymentSummary.ts`
- `backend/app/teaching_quality/TQteacher_employment_summary_api.py`
- `frontend/pages/academic/campus/01-core-data/2-campus-employment-goals-results/campusClassEmploymentInfo.tsx`

### 3.3 新生维稳链路

结论：

- `当月新生维稳明细表` 是维稳链的核心原始表。
- 咨询部交接后会先同步可自动确定的字段；教质部再补报道时间、试学周期、教员、宿舍等字段。
- `新生仍欠费明细表` 由维稳明细和缴费情况派生，欠费清零后会被移除。
- 学术部的维稳统计和每日新生安排页都只是消费结果。

证据：

- `backend/app/services/handover_sync_service.py`
- `backend/app/api/v1/endpoints/consult/handover.py`
- `backend/app/api/v1/endpoints/consult/payment_record.py`
- `frontend/services/teaching-quality/campusNewStudentStability.ts`
- `frontend/pages/teaching-quality/campus/1-core-data/4-new-student-stability/2-monthly-new-stu-stability-detail/1-campus-new-stu-arrears-detail.tsx`

### 3.4 升学与异动链路

- 升学：
  - 先有计划表、月度个人表、月度班级表。
  - 再产出个人年度汇总和校区年度汇总。
- 异动：
  - 先填月度个人明细。
  - 后端视图 `V_校区个人学员异动年汇总` 生成只读年度页。

证据：

- `backend/app/api/v1/endpoints/teaching_quality.py`
- `backend/app/teaching_quality/TQmgnt_promotion_plan_api.py`
- `frontend/pages/teaching-quality/campus/1-core-data/1-core-data-summary/6-promotion-plan/2-campus-personal-promotion-goals-results.tsx`
- `frontend/pages/teaching-quality/campus/1-core-data/1-core-data-summary/7-stu-movement/2-campus-personal-stu-movement-summary.tsx`

## 4. 建议录入顺序

1. 先在配置中心确认校区、班级、班主任等基础数据。
2. 先录入原始业务页：
   - 班级就业信息/班级就业明细
   - 口碑月度个人页
   - 当月新生维稳明细
   - 月度个人升学页、月度班级升学页
   - 月度个人异动明细
3. 再看只读或自动汇总页：
   - 就业明星
   - 班主任就业汇总
   - 个人口碑年度汇总
   - 个人升学年度汇总
   - 个人异动年度汇总
   - 新生仍欠费明细
4. 最后检查：
   - `/teaching-quality/core-data`
   - `/teaching-quality-mgnt-core-business-summary-all`
   - 学术部对应只读消费页

## 5. 每类功能怎么检查

### 5.1 班级链路

1. 在配置中心新增或修改一个班级。
2. 打开教质部班级就业信息、班档案、升学计划页面。
3. 确认班级下拉列表同步出现该班级。

### 5.2 就业链路

1. 在班级就业信息页维护一条学生就业信息。
2. 进入就业明星、班主任就业汇总、班级就业明细页。
3. 再去学术部就业目标与结果汇总页核对是否同步显示。

### 5.3 新生维稳链路

1. 在咨询部交接或缴费页修改一条记录。
2. 打开教质部当月新生维稳明细和新生仍欠费明细。
3. 补齐教质部专有字段后刷新统计页。
4. 再打开学术部维稳只读页确认消费结果。

### 5.4 升学/异动链路

1. 先改月度个人表。
2. 再看年度只读汇总表是否变化。
3. 如果年度页不可编辑，这是正常的视图聚合行为。
