# 口碑页面数据自动获取 - 快速参考

## 数据字段分类速查

### 🔵 自动从咨询量明细表获取
| 字段 | 数据源 | SQL逻辑 |
|------|--------|---------|
| **咨询总量** | 咨询量明细表 | `COUNT(记录ID)` 排除无效量和不算量 |
| **上门总量** | 咨询量明细表 | `SUM(是否上门=1)` |
| **实际招生** | 咨询量明细表 | `SUM(是否报名=1)` |
| **退费人数** | 咨询量明细表 | `SUM(是否退费=1)` |
| **电话量** | 咨询量明细表 | `COUNT(DISTINCT 电话)` 不重复统计 |

### 🟢 自动从计划表获取
| 字段 | 数据源 | 说明 |
|------|--------|------|
| **计划收入** | 咨询师计划表 | 按月度汇总 |
| **计划招生** | 咨询师计划表 | 按月度汇总 |

### 🟡 需要手动输入
| 字段 | 原因 | 未来优化方向 |
|------|------|--------------|
| **实际收入** | 财务数据 | 对接财务系统API |
| **费用投入** | 市场成本数据 | 对接市场成本管理 |

### ⚪ 自动计算
| 字段 | 计算公式 | 特殊处理 |
|------|----------|----------|
| **报名转化率** | 实际招生 ÷ 咨询总量 | 除零显示 `#DIV/0!` |
| **当面转化率** | 实际招生 ÷ 上门总量 | 除零显示 `#DIV/0!` |
| **上门率** | 上门总量 ÷ 咨询总量 | 除零显示 `#DIV/0!` |
| **招生成本** | 费用投入 ÷ 实际招生 | 除零显示 `#DIV/0!` |

## 前端使用

### 导入API
```typescript
import * as statsApi from '@/pages/consult/type-count-system/statsApi'
```

### 调用示例
```typescript
const result = await statsApi.getConsultantMonthlySummary({
  年份: 2026,
  校区: '盛邦',
  数据类型: '口碑'
})

if (result.success) {
  const 张三数据 = result.data.咨询师数据['张三']
  const 一月数据 = 张三数据[1]
  console.log('1月咨询总量:', 一月数据.咨询总量)
  console.log('1月报名量:', 一月数据.报名量)
}
```

## 数据过滤规则

### SQL WHERE条件
```sql
WHERE 
  (是否无效量 = 0 OR 是否无效量 IS NULL)        -- 排除无效量
  AND (是否不算量 = 0 OR 是否不算量 IS NULL)    -- 排除不算量
  AND EXTRACT(YEAR FROM 登记日期) = :年份       -- 按年份筛选
  AND 校区 = :校区                               -- 按校区筛选
  AND 量来源 = :数据类型                         -- 按数据类型筛选
  AND 咨询师 IS NOT NULL                        -- 排除空咨询师
  AND 咨询师 != ''                              -- 排除空字符串咨询师
```

## 故障排查

### 数据不显示
1. 检查是否选择了正确的校区和年份
2. 检查咨询量明细表是否有数据
3. 检查咨询师字段是否为空
4. 检查量来源是否匹配（口碑/网络等）
5. 打开浏览器控制台查看API响应

### 数据不准确
1. 检查是否标记了无效量或不算量
2. 检查登记日期是否在正确年份
3. 检查是否报名/是否上门/是否退费字段是否正确勾选
4. 检查电话字段是否重复（电话量统计会去重）

## 常见问题

**Q: 为什么实际收入不能自动获取？**  
A: 实际收入属于财务数据，需要对接财务系统。目前需手动输入。

**Q: 电话量为什么和咨询总量不一致？**  
A: 电话量统计的是不重复电话数，同一个电话多次咨询只计算一次。

**Q: 转化率显示#DIV/0!是什么意思？**  
A: 表示除数为零，通常是咨询总量或上门总量为0导致。

**Q: 数据更新后为什么没有自动刷新？**  
A: 目前需要手动刷新页面。后续可考虑添加实时更新功能。

**Q: 可以导出数据吗？**  
A: 目前支持表格导出为Excel功能（页面顶部导出按钮）。
