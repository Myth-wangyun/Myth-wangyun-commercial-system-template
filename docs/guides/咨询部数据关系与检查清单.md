- `/consult/type-count-system`
- `/consult/campus-basic-data/daily-consulting-register`
- `/consult/campus-core-data/daily-consulting-summary`
- `/consult/campus-core-data/consultant-data-summary-v3`
- `/consult/campus-basic-data/population-data-summary`
- `/consult/mgnt-center-dashboard`

### 3.2 咨询师数据汇总 V3 的额外依赖

`咨询师数据汇总 V3` 除了咨询量明细，还依赖：

- 咨询师月度计划
- 咨询师分配/职数
- 媒体来源配置

证据：

- `frontend/services/consult/consultantDataSummaryV3.ts`
- `backend/app/api/v1/endpoints/consult/consultant_data_summary_v3.py`

### 3.3 财务收入页的计划口径不是单一来源

结论：

- 页面里的“实际数据”主要来自咨询量明细聚合。
- 页面里的“计划数据”分两类：
  - SEM、新媒体、合作伙伴、免费推广等，依赖市场部月度计划数据
  - 渠道、口碑、校区新媒体等，依赖咨询师月度计划

证据：

- `frontend/pages/consult/004mgmt-data/007-financial-income/index.tsx`
- `frontend/pages/consult/002-campus-yearly-monthly-media-source/002-media-source-yearly/components/GenericSourceDashboard.tsx`
- `frontend/services/consult/consultantPlan.ts`

### 3.4 交接/缴费 -> 教质部维稳同步

结论：

- 咨询页的交接与缴费不是本部门闭环。
- 一旦交接、分班、缴费变更，后端会更新教质部：
  - `当月新生维稳明细表`
  - `新生仍欠费明细表`

证据：

- `frontend/pages/consult/type-count-system/ConsultationList.tsx`
- `frontend/pages/consult/type-count-system/handoverApi.ts`
- `frontend/pages/consult/type-count-system/paymentApi.ts`
- `backend/app/services/handover_sync_service.py`

## 4. 建议录入顺序

1. 先确认系统里的媒体来源/咨询配置正确。
2. 先录入咨询量：
   - `/consult/type-count-system`
   - `/consult/campus-basic-data/daily-consulting-register`
3. 再做分量、转量、交接、缴费。
4. 再录入计划数据：
   - 咨询师月度计划
   - `/consulting/mgnt-center-core-data` 财务页的相关计划口径
   - 需要时回市场部补月度计划
5. 最后检查所有汇总页：
   - 日咨询量汇总
   - 咨询师数据汇总 V3
   - 人群转化数据表
   - 管理中心核心业务数据汇总

## 5. 每类功能怎么检查

### 5.1 录入系统

1. 在 `/consult/type-count-system` 新增一条咨询量。
2. 切到列表、统计、分量、转量 Tab，确认同一条记录可被查询到。
3. 再打开“我的咨询量”和“咨询记录”确认记录一致。

### 5.2 汇总页

1. 新增一条咨询量后刷新：
   - `/consult/campus-core-data/daily-consulting-summary`
   - `/consult/campus-core-data/consultant-data-summary-v3`
   - `/consult/campus-basic-data/population-data-summary`
2. 确认咨询量、上门、报名、退款等指标同步变化。

### 5.3 交接/缴费同步

1. 在录入系统列表里做交接或补款。
2. 到教质部新生维稳明细、欠费明细查看同步结果。
3. 如果教质部字段只同步了一部分，属于源码设计，剩余字段由教质部补录。

### 5.4 财务收入页

1. 先确认咨询实际数据已有记录。
2. 再检查市场月度计划和咨询师月度计划是否已填。
3. 打开 `/consulting/mgnt-center-core-data`，核对计划值与实际值分别来自正确来源。
