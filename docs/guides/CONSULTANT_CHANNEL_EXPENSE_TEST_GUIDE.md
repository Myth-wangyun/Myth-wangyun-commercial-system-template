# 咨询师口碑渠道费用投入编辑功能 - 测试指南

## 测试前准备

1. 确保前端服务正在运行
2. 确保已选择校区
3. 导航到：咨询部 → 校区年度月度来源数据 → 口碑（咨询师）

## 测试步骤

### 测试1: 基本编辑功能

1. 滚动到"咨询师月度明细表"
2. 找到任意咨询师和月份行
3. 在"费用投入"列点击输入框
4. 输入数值（例如：5000）
5. ✅ 验证: 输入框正常接受数字
6. ✅ 验证: "招生成本"列自动更新（如果有实际招生数据）

### 测试2: 合计行自动更新

1. 在同一个月的多个咨询师行输入不同的费用投入
   - 咨询师A: 3000
   - 咨询师B: 4000
   - 咨询师C: 5000
2. ✅ 验证: 该月的合计行"费用投入"自动显示总和（12000）
3. ✅ 验证: 年度总合计行也自动更新

### 测试3: 招生成本计算

假设某咨询师某月数据：
- 费用投入: 6000
- 实际招生: 10

1. 输入费用投入 6000
2. ✅ 验证: 招生成本显示 "600.00"（6000÷10）
3. 修改为 3000
4. ✅ 验证: 招生成本更新为 "300.00"

### 测试4: 边界情况

#### 4.1 零值测试
1. 输入费用投入: 0
2. ✅ 验证: 接受输入，招生成本显示 "-" 或 "0.00"

#### 4.2 实际招生为0
1. 某行实际招生为0或null
2. 输入费用投入: 5000
3. ✅ 验证: 招生成本显示 "-"（避免除零错误）

#### 4.3 负数测试
1. 尝试输入负数: -1000
2. ✅ 验证: 输入框拒绝负数（min=0限制）

#### 4.4 大数值测试
1. 输入大数值: 999999
2. ✅ 验证: 正常接受和显示

### 测试5: 多月批量编辑

1. 为同一咨询师编辑1月到12月的费用投入
2. 输入不同数值（如：1000, 2000, 3000...）
3. ✅ 验证: 每月合计行正确更新
4. ✅ 验证: 年度总合计正确汇总

### 测试6: 合计行不可编辑

1. 找到任意"合计"行
2. 尝试点击费用投入单元格
3. ✅ 验证: 显示为粗体蓝色数字，无输入框，不可编辑

### 测试7: 保存功能（当前为模拟）

1. 编辑多个费用投入数据
2. 点击表格上方的"保存费用投入"按钮
3. ✅ 验证: 显示成功提示消息
4. ⚠️ 注意: 当前为模拟保存，刷新页面数据会丢失

### 测试8: UI响应性

1. 快速连续输入多个费用投入
2. ✅ 验证: 界面响应流畅，无卡顿
3. ✅ 验证: 所有计算实时更新

### 测试9: 清除数据

1. 输入费用投入数值
2. 删除数值（清空输入框）
3. ✅ 验证: 费用投入变为null，招生成本显示"-"
4. ✅ 验证: 合计行正确扣除该值

### 测试10: 整体数据一致性

1. 手动计算某月所有咨询师的费用投入总和
2. ✅ 验证: 与月度合计行的费用投入一致
3. 手动计算12个月度合计的总和
4. ✅ 验证: 与年度总合计的费用投入一致

## 已知限制

⚠️ **数据持久化未实现**
- 刷新页面后，编辑的费用投入数据会丢失
- 需要后端API支持才能实现真正的保存

⚠️ **后端集成待完成**
- "保存费用投入"按钮当前只显示成功提示
- 需要实现API调用将数据发送到后端

## 预期行为总结

### ✅ 应该工作的功能
- 费用投入输入框正常显示和接受输入
- 招生成本自动计算（费用投入÷实际招生）
- 月度合计行自动汇总该月所有咨询师的费用投入
- 年度总合计行自动汇总所有月度合计
- 合计行不可编辑，以粗体蓝色显示
- 只能输入非负数
- 除零等异常情况显示"-"
- 保存按钮显示成功提示

### ❌ 尚未实现的功能
- 真正的数据持久化保存
- 从后端加载已保存的费用投入数据
- 保存数据到数据库
