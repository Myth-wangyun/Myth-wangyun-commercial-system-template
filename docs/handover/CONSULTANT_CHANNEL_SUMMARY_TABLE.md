# 咨询师渠道数据看板 - 更新说明

## 最新修改概述（2026-02-04）

在 `002校区-年月表-各媒体来源` 页面的渠道标签页下，对咨询师部分的所有表格进行了以下更新：

## 计算公式

### 转化率计算（与之前相同）

- **报名转化率** = 实际招生 / 咨询总量
- **当面转化率** = 实际招生 / 上门总量
- **上门率** = 上门总量 / 咨询总量

### 招生成本计算（新增）

- **招生成本** = 费用投入 / 实际招生
- 除零时显示：校区汇总表显示 `#DIV/0!`，其他表显示 `-`
