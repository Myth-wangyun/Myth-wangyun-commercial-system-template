### 2. 统一计算公式

在所有口碑相关表格中，统一使用以下计算公式：

#### 2.1 报名转化率
```
报名转化率 = 实际招生 / 咨询总量 * 100%
```
- 当咨询总量为0或null时，显示 `#DIV/0!`
- 当两者都为0时，显示 `-`

#### 2.2 当面转化率
```
当面转化率 = 实际招生 / 上门总量 * 100%
```
- 当上门总量为0或null时，显示 `#DIV/0!`
- 当两者都为0时，显示 `-`

#### 2.3 上门率
```
上门率 = 上门总量 / 咨询总量 * 100%
```
- 当咨询总量为0或null时，显示 `#DIV/0!`
- 当两者都为0时，显示 `-`

#### 2.4 招生成本
```
招生成本 = 费用投入 / 实际招生
```
- 当实际招生为0或null时，显示 `#DIV/0!`
- 当两者都为0时，显示 `-`
- 显示格式：保留两位小数（不带%符号）

3. 顶部汇总表格实时显示最新的汇总数据

### 7. 技术实现细节

#### 7.1 状态管理
- 使用 React `useState` 管理表格数据
- 使用 `useMemo` 优化汇总数据计算，避免不必要的重渲染

#### 7.2 实时计算
- 用户输入数据时，触发 `updateValue` 函数
- 自动调用 `calculateRates` 计算当前行的转化率和成本
- 自动调用 `recomputeTotal` 重新计算合计行
- 通过 `useMemo` 自动更新汇总表格数据

#### 7.3 除零处理
```typescript
// 示例：报名转化率计算
if (row.咨询总量 && row.咨询总量 > 0 && row.实际招生 !== null) {
  row.报名转化率 = ((row.实际招生 / row.咨询总量) * 100).toFixed(2) + '%'
} else if (row.实际招生 === 0 && row.咨询总量 === 0) {
  row.报名转化率 = '-'
} else if (row.咨询总量 === 0 || row.咨询总量 === null) {
  row.报名转化率 = '#DIV/0!'
} else {
  row.报名转化率 = '-'
}
```

#### 7.4 表格滚动
- 横向滚动：`scroll={{ x: 1600 }}`
- 固定列：序号和校区列设置 `fixed: 'left'`
