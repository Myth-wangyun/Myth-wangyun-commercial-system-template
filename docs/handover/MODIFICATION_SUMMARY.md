## 修改内容

### 1. 数据来源调整

#### 原数据来源
所有数据类型的计划收入和计划人数均从`校区月度财务数据`表获取（手动输入）

#### 新数据来源
根据数据类型从不同来源获取计划数据：

| 数据类型 | 计划收入来源 | 计划人数来源 | 说明 |
|---------|------------|------------|------|
| **SEM** | 市场部年度网络计划表 | 市场部年度网络计划表 | `sem_plan_income` / `sem_plan_signup` |
| **新媒体** | 市场部年度网络计划表 | 市场部年度网络计划表 | `newmedia_plan_income` / `newmedia_plan_signup` |
| **市场口碑** | 市场部口碑月度计划表 | 市场部口碑月度计划表 | `plan_income` / `plan_enrollment` |
| **网络合作伙伴** | 市场部网络合作伙伴月度计划表（汇总） | 市场部网络合作伙伴月度计划表（汇总） | `plan_income` / `plan_enrollment` |
| **口碑** | 校区月度财务数据表 | 校区月度财务数据表 | 保持不变 |
| **渠道** | 校区月度财务数据表 | 校区月度财务数据表 | 保持不变 |
| **校区新媒体** | 校区月度财务数据表 | 校区月度财务数据表 | 保持不变 |

### 2. 修改的API接口

#### 2.1 `/consult/financial/combined-monthly-data-v2`
**功能**：获取合并后的月度数据（计划+实际数据）

**修改点**：
- SEM和新媒体：从`MarketNetworkPlan`表按校区和年份查询，按月份汇总
- 市场口碑：从`市场部口碑月度计划表`按校区和年份查询
- 网络合作伙伴：从`市场部网络合作伙伴月度计划表`按校区和年份查询并汇总
- 其他类型：保持从`校区月度财务数据`表读取

#### 2.2 `/consult/financial/mgnt-core-summary`
**功能**：获取管理中心核心数据汇总（TAB1单个数据类型）

**修改点**：
- SEM和新媒体：从`MarketNetworkPlan`表按年份查询所有校区，按校区分组汇总
- 市场口碑：从`市场部口碑月度计划表`按年份查询，按校区分组汇总
- 网络合作伙伴：从`市场部网络合作伙伴月度计划表`按年份查询，按校区分组汇总
- 其他类型：保持从`校区月度财务数据`表读取

#### 2.3 `/consult/financial/mgnt-core-summary/all`
**功能**：获取管理中心所有数据类型的核心数据汇总（TAB1全部）

**修改点**：
- 构建完整的计划数据映射 `plan_map[(校区, 数据类型)]`
- SEM和新媒体：从`MarketNetworkPlan`表查询并按校区汇总
- 市场口碑：从`市场部口碑月度计划表`查询并按校区汇总
- 网络合作伙伴：从`市场部网络合作伙伴月度计划表`查询并按校区汇总
- 其他类型：从`校区月度财务数据`表查询

### 6. 注意事项

1. **数据一致性**：确保市场部的年度网络计划表和月度详细计划表数据已正确录入
2. **校区名称匹配**：支持模糊匹配，例如"河北盛邦校区"可以匹配"盛邦校区"
3. **月份范围**：
   - 年度网络计划表：month字段为1-12（0为总计行，查询时排除）
   - 月度详细计划表：month字段为1-12
4. **数据汇总**：
   - 网络合作伙伴需要按月份汇总所有合作伙伴的数据
   - SEM和新媒体需要按月份汇总年度网络计划表的数据
