# 咨询师渠道数据看板 - 列结构验证（最终版本）

## ✅ 严格按照要求实现的列结构

### 所有表格统一列结构

```
招生收入 | 招生数据 | 免费推广转化率 | 免费推广招生成本
```

#### 详细列明细：

**招生收入** (2列)
- 计划收入
- 实际收入

**招生数据** (6列)
- 计划招生
- 实际招生
- 退费人数
- 上门总量
- 电话量
- 咨询总量

**免费推广转化率** (3列)
- 报名转化率
- 当面转化率
- 上门率

**免费推广招生成本** (2列)
- 费用投入
- 招生成本

## ⚠️ 重要说明

**咨询师部分的所有表格都不包含"渠道职数"列组！**

这与渠道代理部分不同，咨询师部分只有上述4个列组。

## 代码实现确认

### 列定义代码
```typescript
// 所有表格使用相同的列组
const columns = [
  { title: '序号/月份' },
  { title: '校区/咨询师' },
  { title: '招生收入', children: incomeColumns },      // 2列
  { title: '招生数据', children: enrollmentColumns },  // 6列
  { title: '免费推广转化率', children: channelRateColumns }, // 3列
  { title: '免费推广招生成本', children: channelCostColumns }, // 2列
]
// 总计：2 + 2 + 6 + 3 + 2 = 15列 (不含序号/标识列)
```

## 如何验证

1. 刷新浏览器：`Ctrl+Shift+R`
2. 检查表头是否只有以下4个列组：
   - ✅ 招生收入
   - ✅ 招生数据
   - ✅ 免费推广转化率
   - ✅ 免费推广招生成本
   - ❌ **没有**渠道职数

| 表格宽度 | 1200px | 更宽 |
