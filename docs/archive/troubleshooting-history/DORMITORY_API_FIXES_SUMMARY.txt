================================================================================
                              问题概述
================================================================================

用户反馈以下表单无法正常读取数据库数据：
  ✗ 校区教质部每月个人宿舍管理统计表
  ✗ 个人宿舍管理统计表（手填）
  ✗ 校区教质部宿舍管理统计表
  ✗ 女宿住宿明细
  ✗ 男宿住宿明细
  ✗ 宿舍租赁及缴费信息

================================================================================
                            根本原因分析
================================================================================

问题 1: 校区名称匹配逻辑不统一
  - 多个 API 文件中存在重复的 _norm_campus() 函数定义
  - 每个文件都有自己的实现，导致不一致的行为
  - 受影响文件: 5 个

问题 2: 导入错误
  - campus_female_dormitory_detail_api.py 尝试导入不存在的 _norm_campus 函数
  - 导致模块导入失败，API 无法启动
  - 影响: 女宿住宿明细 API 完全不可用

问题 3: 校区名称查询容错逻辑冗余
  - 每个 API 都手动实现三层容错逻辑
  - 代码重复，难以维护
  - 如果需要修改逻辑，需要修改 5 个文件

================================================================================
                            修复方案
================================================================================

修复 1: 完善 _utils.py (backend/app/teaching-quality/_utils.py)
  ✅ 添加 _norm_campus() 函数作为 normalize_campus() 的别名
  ✅ 优化 campus_variants() 函数的实现
  ✅ 添加空值检查，避免返回空列表

修复 2: 统一 API 中的校区名称查询逻辑
  ✅ campus_male_dormitory_detail_api.py
     - 导入 campus_variants
     - 删除本地 _norm_campus 定义
     - 统一查询逻辑

  ✅ campus_female_dormitory_detail_api.py
     - 修复导入错误（从 _norm_campus 改为 campus_variants）
     - 删除本地 _norm_campus 定义
     - 统一查询逻辑

  ✅ campus_monthly_personal_dormitory_mgmt_api.py
     - 导入 campus_variants
     - 删除本地 _norm_campus 定义
     - 统一查询逻辑

  ✅ campus_dormitory_statistics_summary_api.py
     - 导入 campus_variants
     - 删除本地 _norm_campus 定义
     - 统一查询逻辑（2 处）

  ✅ campus_manager_analysis_api.py
     - 导入 campus_variants
     - 删除本地 _norm_campus 定义
     - 统一查询逻辑

  ✅ campus_dormitory_rent_payment_info_api.py
     - 已使用 campus_variants，无需修改
