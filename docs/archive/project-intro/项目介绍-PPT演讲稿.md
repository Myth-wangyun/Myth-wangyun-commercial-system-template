## 第2页：项目背景
**标题**：为什么要做这个系统？

**内容要点**：
- 传统Excel管理，数据分散难汇总
- 咨询流程不标准，新人培训周期长
- 教员考核不透明，手工计算易出错
- 多校区数据孤岛，管理中心无法实时掌握
- 决策滞后，数据汇总需要1周

**演讲稿**：
在项目启动前，我们调研了多家教育培训机构，发现他们普遍面临五大痛点。首先是数据管理混乱，各种Excel表格分散在不同电脑上，想要汇总分析非常困难。其次是咨询流程不标准，每个咨询师的话术都不一样，新人培训需要2周时间。第三是教员考核不透明，KPI手工计算容易出错，老师们对考核结果有质疑。第四是多校区管理困难，10多个校区的数据各自独立，管理中心无法实时掌握情况。最后是决策滞后，数据汇总需要一周时间，错过了最佳决策时机。

## 第3页：项目目标
**标题**：我们要解决什么问题？

**内容要点**：
- 数据集中管理，实时汇总分析
- 流程标准化，提升工作效率
- 考核透明化，自动计算KPI
- 多校区统一管理，数据实时同步
- 数据驱动决策，响应时间从1周降至1天

**演讲稿**：
基于这些痛点，我们设定了明确的项目目标。首先是实现数据集中管理，所有数据存储在统一的数据库中，支持实时汇总分析。其次是流程标准化，特别是咨询流程，我们设计了16步标准化流程模板。第三是考核透明化，系统自动计算教员KPI，确保公平公正。第四是多校区统一管理，10多个校区的数据实时同步到管理中心。最后是实现数据驱动决策，将决策响应时间从1周缩短到1天。

## 第4页：技术架构
**标题**：系统架构设计

**架构图**：
```
用户浏览器
    ↓
Nginx (反向代理 + HTTPS)
    ↓
前端 (React 19 + TypeScript)
    ↓
后端 (FastAPI + Python 3.12)
    ↓
数据库 (PostgreSQL 17)
```

**演讲稿**：
系统采用前后端分离架构。前端使用React 19和TypeScript，利用最新的并发特性提升性能。后端使用FastAPI框架，这是一个高性能的Python异步框架，性能接近Node.js和Go。数据库选择PostgreSQL 17，它的JSONB字段非常适合存储动态配置。整个系统通过Nginx进行反向代理和负载均衡，支持HTTPS加密传输。

## 第9页：技术难点（1/2）
**标题**：PostgreSQL JSONB性能优化

**问题**：
- JSONB字段查询耗时5-8秒
- 用户体验极差

**解决方案**：
- 创建GIN索引
- 优化查询操作符（`->>` → `@>`）
- 热数据分离

**效果**：
- 查询时间降至200ms
- 性能提升95%

**演讲稿**：
在开发过程中，我遇到的最大技术难点是PostgreSQL JSONB字段的性能问题。当面标准化检查表使用JSONB存储16步咨询内容,初期按内容搜索时查询耗时5到8秒，用户体验极差。我通过三个方面解决：首先创建GIN索引，这是PostgreSQL专门为JSONB设计的索引类型；其次优化查询操作符，从JSON提取改为JSON包含操作符，充分利用索引；最后将常用查询字段提取为独立列，减少JSONB查询。优化后查询时间降至200毫秒，性能提升了95%。

## Q&A环节准备

### 可能的问题1：为什么选择FastAPI而不是Django？
**回答**：FastAPI是异步框架，性能接近Node.js和Go，比Django快3-5倍。而且FastAPI自动生成OpenAPI文档，开发效率更高。我们的系统需要处理高并发场景，FastAPI更适合。

### 可能的问题2：JSONB字段会不会影响数据一致性？
**回答**：不会。JSONB只用于存储动态配置（如16步咨询流程），核心业务数据仍然使用标准的关系型字段。而且PostgreSQL的JSONB支持事务，可以保证数据一致性。

### 可能的问题3：如何保证多校区数据隔离的安全性？
**回答**：我们实施了双重校验机制。第一层是JWT中间件自动注入campus_id过滤条件，第二层是数据库行级权限校验。即使有人绕过了中间件，数据库层面也会拦截。而且所有敏感操作都记录审计日志。

### 可能的问题4：系统如何应对未来的扩展需求？
**回答**：系统采用模块化设计，每个业务模块相对独立。新增功能只需要添加新的模块，不影响现有功能。而且我们使用了JSONB字段存储动态配置，可以灵活适配不同校区的个性化需求。

### 可能的问题5：遇到过最困难的Bug是什么？
**回答**：Windows编码问题。Windows默认GBK编码，Python读取中文文件时出现乱码。我通过设置环境变量、显式指定UTF-8编码、配置数据库连接字符串等多个方面解决。这个问题让我深刻理解了跨平台开发的复杂性。
