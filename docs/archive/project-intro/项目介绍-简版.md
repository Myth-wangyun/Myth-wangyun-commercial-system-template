# 清美教育管理系统 - 项目简介

## 项目概述

清美教育管理系统是为教育培训机构打造的一体化数字化管理平台，覆盖学术、咨询、市场、人力等全业务流程，支持10+校区、500+用户、100万+数据规模。

**技术栈**：React 19 + TypeScript + FastAPI + PostgreSQL 17
**架构**：前后端分离 + RBAC权限 + 多环境部署
**性能**：API响应<300ms、并发500人、可用性99.9%

---

## 核心功能模块

### 1. 学术部管理
- 教员KPI自动计算、功能分析（听课/违纪/合格率）
- 教学质量管理（作业/考试/项目成绩）
- 学员满意度调查、稳定性追踪
- 口碑招生目标与结果汇总
- 就业管理（班级就业信息、薪资预估）

### 2. 咨询部管理
- 咨询量录入、统计、保护期、转量管理
- 标准化检查表（16步咨询流程）
- 咨询师数据汇总、月度计划
- 沟通记录、缴费记录管理

### 3. 校区管理
- 核心数据实时汇总（就业/口碑/稳定性）
- 目标与结果对比分析
- 新生维稳、流失明细
- 企业文化宣讲与考试

### 4. 权限与审计
- RBAC权限系统（15角色、80+权限点）
- 审计日志、操作追踪
- 多校区数据隔离

---

## 技术架构

```
前端：React 19 + TypeScript + Vite + Ant Design 5
     Zustand (状态) + React Query (数据获取)

后端：FastAPI + Python 3.12 + SQLAlchemy 2.0
     JWT认证 + RBAC权限 + 限流中间件

     多Schema设计 (academic/consult/market)
```

## 我的核心贡献

### 1. 当面标准化检查表系统
- **功能**：16步咨询流程模板化、预案/复盘管理、多校区支持
- **技术**：JSONB动态字段、模板配置系统、图片导出
- **成果**：4000行代码，咨询师录入效率提升40%，标准化率95%

### 2. 高并发登录优化
- **问题**：早高峰登录成功率仅70%，响应时间3.2s
- **方案**：JWT密钥轮换、限流优化、连接池调优、Redis缓存
- **成果**：成功率99.5%、响应0.8s、支持500并发

### 3. RBAC权限系统重构
- **功能**：角色-权限-菜单三级控制、数据权限隔离
- **技术**：5张权限表、JWT中间件、动态菜单生成
- **成果**：15角色80+权限点、数据隔离100%、0安全漏洞

### 4. 动态列配置功能
- **功能**：用户自定义表格列、列顺序、列宽
- **技术**：拖拽排序、JSONB存储配置
- **成果**：覆盖35个页面、78%用户使用、效率提升30%

### 5. 数据导出功能
- **功能**：Excel导出（带样式）、图片导出（微信分享）
- **技术**：ExcelJS、html2canvas、Web Worker
- **成果**：1000行<3s、日均2000+次导出

## 核心技术难点

### 1. JSONB查询性能优化
**问题**：JSONB字段查询耗时5-8秒
**方案**：GIN索引 + `@>`操作符 + 热数据分离
**效果**：查询时间降至200ms，性能提升95%

### 2. 大数据量表格渲染
**问题**：2000+行数据滚动卡顿，FPS降至15
**方案**：虚拟滚动 + 分页加载 + 防抖 + memo优化
**效果**：FPS提升至60，流畅度提升300%

### 3. 多校区数据隔离与聚合
**问题**：10+校区数据隔离，同时支持管理中心聚合
**方案**：campus_id字段 + 中间件注入 + 行级权限
**效果**：数据隔离100%、聚合查询<500ms

### 4. Excel导出样式丢失
**问题**：xlsx库导出样式全部丢失
**方案**：切换至ExcelJS + 样式模板 + 公式支持
**效果**：样式完整度100%、用户满意度95%

### 5. JWT令牌过期问题
**问题**：30分钟过期导致频繁登录
**方案**：Refresh Token + 自动刷新 + 密钥轮换
**效果**：7天免登录、登录频率降低95%
