# 清美教育管理系统（简历版）

## 项目名称
清美教育管理系统（QM System）

## 项目时间
2025.08 - 2026.01（6个月）

## 项目角色
后端开发工程师 + 部分前端开发

## 项目描述
教育培训机构一体化数字化管理平台，覆盖学术、咨询、市场、人力等全业务流程。系统采用前后端分离架构，支持10+校区、500+用户、100万+数据规模，实现了咨询转化率提升15%、教学质量提升20%、运营成本降低30%的业务目标。

## 技术栈
- **前端**：React 19、TypeScript、Vite、Ant Design 5、Zustand、React Query
- **后端**：FastAPI、Python 3.12、SQLAlchemy 2.0、JWT、APScheduler
- **数据库**：PostgreSQL 17、JSONB、GIN索引、多Schema设计
- **部署**：Nginx、Docker、主从复制、负载均衡

## 主要职责

### 1. 咨询部核心功能开发（4000行代码）
- 实现当面标准化检查表系统，包含16步咨询流程模板化、预案/复盘管理、多校区支持
- 使用PostgreSQL JSONB字段存储动态配置，实现灵活的模板系统
- 开发图片导出功能（html2canvas），支持微信分享
- **成果**：咨询师录入效率提升40%，标准化率从60%提升至95%

### 2. 高并发登录性能优化
- 解决早高峰登录成功率仅70%、响应时间3.2秒的性能瓶颈
- 实施JWT密钥轮换机制、Refresh Token自动刷新、限流中间件优化
- 优化数据库连接池（20→100连接）、引入Redis缓存用户信息
- **成果**：登录成功率提升至99.5%，响应时间降至0.8秒，支持500并发

### 3. RBAC权限系统重构
- 从简单角色判断重构为完整的RBAC权限系统，实现角色-权限-菜单三级控制
- 设计5张权限表，实现数据权限隔离和多校区数据100%隔离
- 开发JWT中间件、动态菜单生成、按钮级权限控制
- **成果**：15角色80+权限点、通过渗透测试0安全漏洞

### 4. 数据库性能优化
- 解决PostgreSQL JSONB字段查询耗时5-8秒的性能问题
- 创建GIN索引、优化查询操作符（`->>` → `@>`）、热数据分离
- 优化复杂查询SQL，使用EXPLAIN ANALYZE分析执行计划
- **成果**：查询时间降至200ms，性能提升95%

### 5. 前端性能优化
- 解决2000+行数据表格渲染卡顿问题（FPS降至15）
- 实现虚拟滚动（react-window）、分页加载、防抖优化、React.memo优化
- 开发动态列配置功能，支持用户自定义表格列、列顺序、列宽
- **成果**：FPS提升至60（提升300%），覆盖35个页面，78%用户使用

### 6. 数据导出功能开发
- 实现Excel导出（ExcelJS，支持样式、合并单元格、公式）
- 实现图片导出（html2canvas，支持自定义尺寸、水印）
- 优化大数据量导出性能，使用Web Worker后台处理
- **成果**：1000行数据<3秒，日均2000+次导出，用户满意度95%

## 核心技术亮点

### 1. PostgreSQL JSONB性能优化
- **问题**：JSONB字段查询耗时5-8秒
- **方案**：GIN索引 + `@>`操作符 + 热数据分离
- **效果**：查询时间降至200ms，性能提升95%

### 2. 多校区数据隔离与聚合
- **方案**：campus_id字段 + 中间件自动注入 + 行级权限校验
- **效果**：数据隔离100%、聚合查询<500ms

### 3. JWT Refresh Token机制
- **方案**：Access Token（30分钟）+ Refresh Token（7天）+ 自动刷新
- **效果**：7天免登录、登录频率降低95%

### 4. 虚拟滚动优化大表格
- **方案**：react-window + 分页加载 + 防抖 + memo
- **效果**：FPS从15提升至60，流畅度提升300%

## 项目成果
- **用户规模**：10+校区、500+用户、日活300+
- **数据规模**：100万+条记录、日增5000+条
- **性能指标**：API响应<300ms、页面加载<2s、并发支持500人
- **业务效果**：咨询转化率↑15%、教学质量↑20%、运营成本↓30%
