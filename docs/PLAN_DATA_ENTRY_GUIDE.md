# 计划收入与计划招生数据填写指南

## 一、数据入口总览

计划数据（计划收入、计划招生）有 **两个独立的填写入口**，分别对应不同的管理层级。两个入口互不关联，数据各自独立存储。

### 入口 A：校区级计划数据 — 007 TAB2 校区月度数据

**路径**：咨询部门 → 财务收入和退费 → 选择校区 → TAB2 校区月度数据 → 选择数据类型

在每个数据类型的月度表格中，直接编辑每月的 **计划收入** 和 **计划招生**。

- **存储表**：`consult.校区月度财务数据`
- **唯一键**：年份 + 月份 + 校区 + 数据类型
- **数据用途**：供 001 管理中心看板、002 TAB1 校区核心数据、002 各TAB子表1/子表2、003 页面、007 页面使用

### 入口 B：咨询师级计划数据 — 002 各TAB 子表4

**路径**：咨询部门 → 校区年度及月度数据 → 选择校区 → 选择TAB（SEM/新媒体/市场口碑等） → 子表4 咨询师月度明细表

在子表4中填写每个咨询师每月的 **计划收入** 和 **计划招生**。

- **存储表**：`consult.咨询师月度计划数据`
- **唯一键**：年份 + 月份 + 校区 + 咨询师 + 数据类型
- **数据用途**：仅供 002 各TAB子表3/4、003 咨询师看板子表2/3使用

> ⚠️ **重要原则**：咨询师级数据 **不向上汇总** 到校区级。因为咨询师人员变动频繁，按咨询师细分不方便制定校区整体目标。校区级目标在入口A独立设定。

## 二、数据填写步骤

### 入口 A：填写校区级计划数据（007 TAB2）

#### 步骤 A1：进入007页面
1. 登录系统
2. 左侧菜单 → 咨询部门 → 财务收入和退费
3. 顶部选择 **校区**（如：盛邦、冀美等）
4. 顶部选择 **年份**
5. 切换到 **TAB2 校区月度数据**

#### 步骤 A2：选择数据类型并填写
在TAB2中选择数据类型（SEM / 新媒体 / 市场口碑 / 网络合作伙伴 / 口碑 / 渠道 / 校区新媒体 / 免费推广），每种类型有独立的月度表格。

可编辑字段：
- **计划收入**：该校区该月该类型的收入计划（单位：元）
- **计划招生**：该校区该月该类型的招生计划（单位：人）

#### 步骤 A3：确认数据去向
保存后，数据自动出现在以下位置：

```
007 TAB2（校区月度数据）── 直接编辑保存
  ├── → 007 TAB1 核心数据汇总：各数据类型年度汇总
  ├── → 001 管理中心看板：全校区计划收入/计划招生
  ├── → 002 TAB1 校区核心数据各子看板：按数据类型直读
  ├── → 002 各TAB 子表1 年度汇总表：按校区聚合年度计划
  └── → 002 各TAB 子表2 月度数据表：按月份直读计划数据
```

---

### 入口 B：填写咨询师级计划数据（002 子表4）

#### 步骤 B1：进入002页面
1. 登录系统
2. 左侧菜单 → 咨询部门 → 校区年度及月度数据
3. 顶部选择 **校区**（如：盛邦、冀美等）
4. 顶部选择 **年份**

#### 步骤 B2：选择数据类型TAB

| TAB | 说明 |
|-----|------|
| SEM（网络） | SEM/百度推广渠道 |
| 新媒体 | 抖音、快手等新媒体渠道 |
| 市场口碑 | 市场口碑渠道 |
| 合作伙伴 | 百教网、91搜客等合作平台 |
| 口碑 | 学员转介绍等 |
| 渠道 | 渠道代理（有独立的咨询师子TAB） |
| 校区新媒体 | 各校区自运营新媒体 |

#### 步骤 B3：在子表4填写数据
1. 滚动到页面底部，找到 **"咨询师月度明细表"**（子表4）
2. 每一行对应一个咨询师的某月数据
3. 可编辑字段：
   - **计划收入**：该咨询师该月的收入计划（单位：元）
   - **计划招生**：该咨询师该月的招生计划（单位：人）
   - **费用投入**：（部分TAB可编辑）市场投入费用
4. 填写完成后点击 **"保存计划数据"** 按钮

#### 步骤 B4：确认级联更新
保存后，数据 **仅在咨询师级别** 级联：

```
子表4（咨询师月度明细）── 直接编辑保存
  ├── → 002 子表3（咨询师汇总表）：前端按咨询师聚合12个月的计划数据
  └── → 003 咨询师看板 子表2/3：后端直读咨询师计划数据

❌ 不会汇总到：子表1、子表2、TAB1、001、007
```

## 四、各页面数据来源说明

### 数据入口
计划数据有 **两个层级** 的入口：

| 层级 | 入口 | 存储表 | 用途 |
|------|------|--------|------|
| **校区级** | 007 TAB2 校区月度数据 | `consult.校区月度财务数据` | 002 TAB1、002 子表1/2、007、001 |
| **咨询师级** | 002 各TAB 子表4 咨询师月度明细 | `consult.咨询师月度计划数据` | 002 子表3/4、003 子表2/3 |

> ⚠️ 咨询师级数据不向上汇总到 TAB1。因为咨询师人员变动频繁，按咨询师细分不方便制定校区整体目标。

### 001 管理中心 - 核心数据看板汇总
| 字段 | 数据来源 |
|------|---------|
| 计划收入 | 校区月度财务数据表（各数据类型年度汇总） |
| 实际收入 | 咨询量统计系统自动汇总 |
| 收入完成率 | 自动计算：实际收入÷计划收入×100% |
| 计划招生 | 校区月度财务数据表（各数据类型年度汇总） |

### 002 校区年度月度数据
| 表格 | 计划收入来源 | 计划招生来源 | 层级 |
|------|------------|------------|------|
| TAB1 校区核心数据各子看板 | 校区月度财务数据表（按数据类型直读） | 同左 | 校区级 |
| 各TAB 子表1 年度汇总 | 校区月度财务数据表（后端按校区聚合年度） | 同左 | 校区级 |
| 各TAB 子表2 月度数据 | 校区月度财务数据表（按月份直读） | 同左 | 校区级 |
| 各TAB 子表3 咨询师汇总 | 前端从子表4按咨询师聚合12个月 | 同左 | 咨询师级 |
| 各TAB 子表4 咨询师月度明细 | **直接填写**（咨询师级入口B） | **直接填写** | 咨询师级 |

### 003 咨询师数据看板

003 同样有两个数据层级，结构与 002 类似：

| 视图 | 计划数据来源 | 层级 |
|------|------------|------|
| 子表1（预留校区汇总） | 校区月度财务数据表（与002子表1/007统一） | 校区级 |
| 子表2 按月查看（咨询师月度） | 后端直读 `consult.咨询师月度计划数据` | 咨询师级 |
| 子表3 年度汇总（咨询师年度） | 后端直读 `consult.咨询师月度计划数据` | 咨询师级 |

#### 003 与 007 数据类型映射

003 的分类与 007 `校区月度财务数据` 的 data_type 对应关系：

| 003 分类 | 003 子分类 | 007 数据类型（校区月度财务数据） |
|---------|-----------|-------------------------------|
| **网络** | 常规（传统）推广 | SEM、合作伙伴、市场口碑、免费推广 |
| **网络** | 新媒体 | 新媒体 |
| **渠道** | — | 渠道 |
| **口碑** | — | 口碑 |

### 007 财务收入和退费
| 表格 | 计划收入来源 |
|------|------------|
| TAB1 核心数据汇总 | 汇总各校区×各数据类型的年度计划 |

## 五、收入完成率说明

### 计算公式
$$\text{收入完成率} = \frac{\text{实际收入}}{\text{计划收入}} \times 100\%$$

### 显示规则
- 当计划收入 > 0 且实际收入有值时：显示百分比（保留1位小数），如 `85.3%`
- 当计划收入为0或空时：显示 `-` 或 `#DIV/0!`（不同页面风格不同）

### 已实现页面

| 页面 | 状态 | 显示位置 |
|------|------|---------|
| 001 管理中心看板 | ✅ | 全校区及平台招生收入分组下 |
| 002 各TAB通用看板 | ✅ | 招生收入列组中（计划收入、实际收入之后） |
| 002 渠道咨询师看板 | ✅ | 招生收入列组中 + 校区汇总表 |
| 003 咨询师数据看板 | ✅ | 后端计算，前端渲染 |
| 007 核心数据汇总 | ✅ | 计划收入、实际收入之后 |
| 007 各数据类型子表 | ✅ | 计划收入、实际收入之后 |
| 007 校区月度数据 | ✅ | 各数据类型列组中 |
| 007 校区数据汇总 | ✅ | 汇总表中 |

## 六、常见问题

### Q1：为什么我填了计划数据，但其他表格没显示？
**A**：请确认以下几点：
1. 点击了"保存计划数据"按钮
2. 填写的校区和年份与要查看的页面一致
3. 填写的数据类型TAB（如SEM/新媒体等）正确
4. 刷新目标页面（如001/007）

### Q2：子表2和子表3的计划数据为什么编辑不了？
**A**：
- **子表2**（月度数据）的计划数据来自校区月度财务数据表（007 TAB2 填写），属于校区级，不能在此直接编辑。请到 007 TAB2 修改。
- **子表3**（咨询师汇总）的计划数据是从子表4自动聚合而来的，不能直接编辑。请在子表4中按咨询师×月份维度填写。

### Q3：渠道TAB的数据怎么填？
**A**：渠道TAB有两个子TAB：
- **咨询师**：在"咨询师月度明细表"中填写（与其他TAB一致）
- **渠道代理**：无需填写计划数据（渠道代理不涉及计划收入）

### Q4：007页面的计划数据和002的是同一个吗？
**A**：不是同一个，它们是两个独立的数据层级：
- **007 TAB2** 编辑的是 **校区级** 计划数据，存入 `consult.校区月度财务数据` 表
- **002 子表4** 编辑的是 **咨询师级** 计划数据，存入 `consult.咨询师月度计划数据` 表

两张表完全独立，互不影响。校区级目标不等于咨询师目标之和。

### Q5：002 子表1和子表2的计划数据从哪里来？
**A**：子表1（年度汇总表）和子表2（月度数据表）的计划收入和计划招生都来自 **校区级**（`consult.校区月度财务数据`），即 007 TAB2 中填写的数据，而不是从子表4的咨询师数据汇总而来。

### Q6：收入完成率显示 `-` 或 `#DIV/0!` 是什么意思？
**A**：表示计划收入为0或未填写，无法计算完成率。请先填写计划收入数据。
