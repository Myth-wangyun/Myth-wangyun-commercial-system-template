# 数据库和表结构说明

本文档列出了系统运行后创建的所有数据库和数据表。

## 数据库列表

系统使用 PostgreSQL 17，共创建以下数据库：

### 1. 核心数据库

| 数据库名 | 说明 | 用途 |
|---------|------|------|
| `account` | 账户数据库 | 存储用户信息、企业文化相关数据 |

### 2. 功能模块数据库

| 数据库名 | 说明 | 用途 |
|---------|------|------|
| `市场` | 市场模块数据库 | 存储市场投放数据、合作方信息、各校区投放明细 |
| `就业` | 就业模块数据库 | 存储就业明细数据 |

### 3. 校区数据库（可选，根据配置创建）

| 数据库名 | 说明 | 校区代码 |
|---------|------|---------|
| `shengbang_db` | 盛邦校区数据库 | shengbang |
| `jimei_db` | 冀美校区数据库 | jimei |
| `jinmei_db` | 晋美校区数据库 | jinmei |
| `shimei_db` | 石美校区数据库 | shimei |
| `taimei_db` | 太美校区数据库 | taimei |
| `guimei_db` | 桂美校区数据库 | guimei |
| `yuanmei_db` | 原美校区数据库 | yuanmei |

**注意**: 校区数据库在 `create_all_campus_databases()` 函数中创建，但当前初始化流程 (`init_db()`) 中不会自动创建这些数据库。

## 数据库初始化流程

系统初始化时会按以下顺序创建数据库和表：

1. **创建 account 数据库**
   - 创建 `users` 表
   - 导入用户数据（包括默认管理员用户）
   - 创建 `企业文化宣讲计划表`
   - 创建 `企业文化考试计划表`

2. **创建市场数据库**
   - 创建 `投放明细表`
   - 创建 `合作方联系方式表`
   - 插入合作方数据
   - 创建各校区投放明细表（7个校区表）

3. **创建就业数据库**
   - 创建 `班级就业明细表`

## 统计信息

### 数据库总数
- **核心数据库**: 1个（account）
- **功能模块数据库**: 2个（市场、就业）
- **校区数据库**: 7个（可选，根据配置创建）
- **总计**: 10个数据库（如果创建所有校区数据库）

### 数据表总数
- **account 数据库**: 4个表
- **市场 数据库**: 9个表（1个投放明细表 + 1个合作方表 + 7个校区投放明细表）
- **就业 数据库**: 1个表
- **总计**: 14个表

## 注意事项

1. **PostgreSQL 特性**:
   - 所有数据库使用 UTF8 编码
   - 表名和字段名支持中文
   - 索引名必须全局唯一（因此校区表使用表名前缀）

2. **数据初始化**:
   - `users` 表会自动创建默认管理员用户（admin/admin123）
   - `合作方联系方式表` 会自动插入初始数据
   - 各校区投放明细表初始为空

3. **索引优化**:
   - 所有表都创建了必要的索引以优化查询性能
   - 校区表的索引名包含表名，避免冲突

4. **时间戳**:
   - 所有表都有 `创建时间` 和 `更新时间` 字段
   - PostgreSQL 使用触发器自动更新 `更新时间`
