## 🛠️ 导入方法

### 方法1: Python脚本导入（推荐）

#### 完整版导入脚本
```bash
cd tools
python import_employees.py
```

**特点:**
- 详细的导入过程显示
- 完整的错误处理
- 数据验证和统计
- 支持重复运行（跳过已存在用户）

#### 快速导入脚本
```bash
cd tools
python quick_import_employees.py
```

**特点:**
- 快速导入，适合批量操作
- 简化的错误处理
- 适合自动化部署

### 方法2: SQL脚本导入

```bash
# 在MySQL中执行
mysql -u username -p database_name < sql/insert_employees.sql
```

**特点:**
- 直接数据库操作
- 适合数据库管理员
- 支持事务回滚

## 🔧 自定义配置

### 修改默认密码
在导入脚本中修改密码生成规则：
```python

default_password = employee_data["username"] + "123456"

# 自定义规则
default_password = "Qingmei" + employee_data["username"] + "2025"
```

### 修改邮箱域名
```python
# 原设置

# 自定义域名
email=f"{employee_data['username']}@yourcompany.com"
```

## ⚠️ 注意事项

### 安全建议
1. **首次登录后修改密码** - 所有员工应在首次登录后修改默认密码
2. **定期密码更新** - 建议定期更新员工密码
3. **权限最小化** - 根据实际工作需要分配最小必要权限

### 数据维护
1. **定期备份** - 定期备份用户数据
2. **数据同步** - 与HR系统保持数据同步
3. **离职处理** - 及时处理离职员工账户

### 错误处理
1. **重复导入** - 脚本会自动跳过已存在的用户
2. **数据验证** - 导入前会验证数据格式
3. **事务回滚** - 出错时会自动回滚事务

## 📞 技术支持

如果在导入过程中遇到问题，请检查：

1. **数据库连接** - 确保数据库服务正常运行
2. **权限设置** - 确保有足够的数据库操作权限
3. **依赖包** - 确保所有Python依赖包已安装
4. **数据格式** - 检查员工数据格式是否正确
