# 清美教育管理系统 - 项目简介

## 🎯 项目概述

清美教育管理系统是一个专为教育机构设计的综合管理平台，主要用于管理市场投放数据、合作伙伴信息、校区信息等核心业务数据。

### 核心价值
- **数据驱动决策**: 提供完整的市场投放数据分析和可视化
- **合作伙伴管理**: 统一管理各类合作伙伴信息
- **校区信息展示**: 集中展示各校区基本信息
- **高效数据录入**: 简化的数据录入和批量处理功能

## 🏗️ 系统架构

### 技术栈
- **后端**: Python + FastAPI + SQLAlchemy + MySQL
- **前端**: HTML5 + JavaScript ES6 + Bootstrap 5 + Chart.js
- **数据库**: MySQL 8.0
- **部署**: 本地开发环境

### 核心模块
1. **日投放数据登记** - 日常市场投放数据录入
2. **统计分析** - 多维度数据分析和可视化
3. **合作方管理** - 合作伙伴信息管理
4. **校区信息** - 校区基本信息展示

## 🚀 主要功能

### 1. 日投放数据登记
- **数据录入**: 支持单条和批量数据录入
- **数据验证**: 完整的数据验证和错误提示
- **实时统计**: 10个关键指标实时统计卡片
- **筛选功能**: 支持按日期、媒体来源筛选

### 2. 统计分析
- **多维度统计**: 按日、周、月、年统计
- **可视化图表**: 消费、点击、对话等趋势图
- **关键指标**: 点击率、转化率、留电率等
- **数据导出**: 支持数据导出功能

### 3. 合作方管理
- **信息管理**: 完整的合作伙伴信息管理
- **分类管理**: 8种合作方类型分类
- **搜索筛选**: 支持多条件搜索和筛选
- **CRUD操作**: 完整的增删改查功能

### 4. 校区信息
- **信息展示**: 各校区基本信息展示
- **数据管理**: 校区数据的维护和更新
