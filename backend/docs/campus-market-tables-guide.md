# 各校区投放明细表功能使用指南

## 功能概述

本功能实现了在市场数据库下创建各校区的投放明细表，支持根据前端用户选择的校区向对应的表中插入数据。其中校园校区对应石美校区。

## 已创建的投放明细表

在市场数据库下已创建以下投放明细表：

1. **盛邦投放明细表** - 盛邦校区
2. **冀美投放明细表** - 冀美校区  
3. **石美投放明细表** - 石美校区（校园校区）
4. **晋美投放明细表** - 晋美校区
5. **原美投放明细表** - 原美校区
6. **太美投放明细表** - 太美校区
7. **桂美投放明细表** - 桂美校区

## 表结构

每个投放明细表包含以下字段：

- `投放ID` - 主键，自增
- `日期` - 投放日期
- `校区` - 所属校区（自动设置为对应校区名称）
- `媒体来源` - 媒体来源
- `关键词` - 关键词
- `展现次数` - 展现次数
- `点击次数` - 点击次数
- `消费金额` - 消费金额
- `咨询次数` - 咨询次数
- `转化次数` - 转化次数
- `备注` - 备注
- `创建时间` - 创建时间
- `更新时间` - 更新时间

## API 使用方式

### 1. 创建投放明细

**请求方式**: POST  
**URL**: `/api/v1/campus-market/`  
**请求头**: `X-Campus: 校区名称`

**支持的校区**:
- 盛邦校区
- 冀美校区
- 石美校区
- 晋美校区
- 原美校区
- 太美校区
- 桂美校区

**请求体示例**:
```json
{
    "日期": "2024-01-15",
    "媒体来源": "百度推广",
    "关键词": "清美教育",
    "展现次数": 1000,
    "点击次数": 50,
    "消费金额": 500.00,
    "咨询次数": 10,
    "转化次数": 2,
    "备注": "测试数据"
}
```

### 2. 获取投放明细列表

**请求方式**: GET  
**URL**: `/api/v1/campus-market/`  
**请求头**: `X-Campus: 校区名称`

**查询参数**:
- `跳过` - 跳过的记录数（分页）
- `限制` - 限制返回的记录数（分页）
- `日期_开始` - 开始日期筛选
- `日期_结束` - 结束日期筛选
- `媒体来源` - 媒体来源筛选

### 3. 获取单条投放明细

**请求方式**: GET  
**URL**: `/api/v1/campus-market/{投放ID}`  
**请求头**: `X-Campus: 校区名称`

### 4. 更新投放明细

**请求方式**: PUT  
**URL**: `/api/v1/campus-market/{投放ID}`  
**请求头**: `X-Campus: 校区名称`

**请求体示例**:
```json
{
    "展现次数": 1200,
    "点击次数": 60,
    "消费金额": 600.00
}
```

### 5. 删除投放明细

**请求方式**: DELETE  
**URL**: `/api/v1/campus-market/{投放ID}`  
**请求头**: `X-Campus: 校区名称`

### 6. 获取投放统计

**请求方式**: GET  
**URL**: `/api/v1/campus-market/statistics/overview`  
**请求头**: `X-Campus: 校区名称`

**查询参数**:
- `日期_开始` - 开始日期
- `日期_结束` - 结束日期

## 数据库初始化

系统会在初始化时自动创建所有校区的投放明细表。可以通过以下方式重新初始化：

```python
from backend.app.core.database import init_db

# 执行数据库初始化
success = init_db()
```

## 注意事项

1. **校区选择**: 前端必须通过 `X-Campus` 请求头指定校区，系统会根据校区选择对应的投放明细表进行操作。

2. **数据隔离**: 每个校区的数据完全隔离，互不影响。

3. **校园校区映射**: 校园校区在系统中映射为石美校区。

4. **必填字段**: 创建投放明细时，`日期`、`媒体来源`、`消费金额` 为必填字段。

5. **数据类型**: 消费金额使用 `DECIMAL(10,2)` 类型，确保精度。
