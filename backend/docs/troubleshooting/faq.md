# 常见问题解答 (FAQ)

## 🚀 系统部署问题

### Q1: 如何启动系统？
**A**: 使用启动脚本是最简单的方式：
```bash
# Windows PowerShell
.\start.ps1

# 或者手动启动
python -m http.server 3000 --directory fronted/
python backend/main.py
```

### Q2: 端口被占用怎么办？
**A**: 检查并终止占用端口的进程：
```bash
# 检查端口占用
netstat -an | findstr :3000
netstat -an | findstr :8000

# 终止Python进程
taskkill /f /im python.exe
```

### Q3: 数据库连接失败？
**A**: 检查以下配置：
1. MySQL服务是否启动
2. 数据库连接配置是否正确
3. 数据库用户权限是否足够
4. 防火墙是否阻止连接

### Q4: PowerShell执行策略问题？
**A**: 临时绕过执行策略：
```bash
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

## 🗄️ 数据库问题

### Q12: 如何查看数据库中的数据？
**A**: 使用MySQL客户端：
```bash
# 连接数据库
mysql -u root -p 市场

# 查看表结构
DESCRIBE 投放明细表;
DESCRIBE 合作方联系方式表;

# 查看数据
SELECT COUNT(*) FROM 投放明细表;
SELECT * FROM 投放明细表 LIMIT 5;
```

### Q13: 如何备份数据库？
**A**: 使用mysqldump命令：
```bash
# 备份数据库
mysqldump -u root -p 市场 > backup.sql

# 恢复数据库
mysql -u root -p 市场 < backup.sql
```

### Q14: 如何重置数据库？
**A**: 重新导入数据库结构：
```bash
# 删除并重建数据库
mysql -u root -p -e "DROP DATABASE 市场; CREATE DATABASE 市场 CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;"

# 导入表结构
mysql -u root -p 市场 < sql/create_table.sql
mysql -u root -p 市场 < sql/create_statistics_views.sql
```

## 🔐 权限和安全问题

### Q22: 如何设置数据库用户权限？
**A**: 创建专用数据库用户：
```sql
-- 创建用户
CREATE USER 'qm_user'@'localhost' IDENTIFIED BY 'password';

-- 授权
GRANT ALL PRIVILEGES ON 市场.* TO 'qm_user'@'localhost';

-- 刷新权限
FLUSH PRIVILEGES;
```

### Q23: 如何保护API接口？
**A**: 建议的安全措施：
1. 使用HTTPS协议
2. 实施API访问限制
3. 添加身份验证
4. 记录访问日志
