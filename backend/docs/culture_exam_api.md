# 企业文化考试计划表 API 文档

## 概述

企业文化考试计划表 API 用于管理各校区、各年月的考试计划数据。

**基础路径**: `/api/v1/culture-exam`

## API 端点

### 1. 获取考试计划

**GET** `/{campus}/{year}/{month}`

获取指定校区、年份、月份的考试计划。

**路径参数**:
- `campus` (string): 校区名称，如 "盛邦校区"
- `year` (int): 年份，范围 2000-2100
- `month` (int): 月份，范围 1-12

**响应示例**:
```json
{
  "校区名称": "盛邦校区",
  "年份": 2024,
  "月份": 12,
  "行数据": [
    {
      "计划ID": 1,
      "校区名称": "盛邦校区",
      "年份": 2024,
      "月份": 12,
      "序号": 1,
      "考试时间": "2024-12-15",
      "考试地点": "教室A",
      "考试方式": "笔试",
      "考试主题": "企业文化基础知识",
      "考试对象": "全体员工",
      "组织人": "张三",
      "监考人": "李四",
      "需准备资料": "试卷、答题卡",
      "备注": "无",
      "创建时间": "2024-12-01T10:00:00",
      "更新时间": "2024-12-01T10:00:00"
    }
  ],
  "创建时间": "2024-12-01T10:00:00",
  "更新时间": "2024-12-01T10:00:00"
}
```

### 2. 创建考试计划

**POST** `/`

创建新的考试计划（批量创建多行）。

**请求体**:
```json
{
  "校区名称": "盛邦校区",
  "年份": 2024,
  "月份": 12,
  "行数据": [
    {
      "序号": 1,
      "考试时间": "2024-12-15",
      "考试地点": "教室A",
      "考试方式": "笔试",
      "考试主题": "企业文化基础知识",
      "考试对象": "全体员工",
      "组织人": "张三",
      "监考人": "李四",
      "需准备资料": "试卷、答题卡",
      "备注": "无"
    }
  ]
}
```

**响应**: 同获取考试计划响应格式

### 3. 更新考试计划

**PUT** `/{campus}/{year}/{month}`

更新指定校区、年份、月份的考试计划（批量更新）。

**路径参数**: 同获取考试计划

**请求体**:
```json
{
  "行数据": [
    {
      "序号": 1,
      "考试时间": "2024-12-15",
      "考试地点": "教室A",
      "考试方式": "笔试",
      "考试主题": "企业文化基础知识",
      "考试对象": "全体员工",
      "组织人": "张三",
      "监考人": "李四",
      "需准备资料": "试卷、答题卡",
      "备注": "无"
    }
  ]
}
```

**响应**: 同获取考试计划响应格式

### 4. 删除考试计划

**DELETE** `/{campus}/{year}/{month}`

删除指定校区、年份、月份的考试计划。

**路径参数**: 同获取考试计划

**响应**:
```json
{
  "success": true,
  "message": "成功删除 10 条记录",
  "deleted_count": 10
}
```

### 5. 获取单行考试计划

**GET** `/row/{plan_id}`

根据计划ID获取单行考试计划。

**路径参数**:
- `plan_id` (int): 计划ID

**响应**: 单行考试计划数据（格式同行数据）

### 6. 更新单行考试计划

**PUT** `/row/{plan_id}`

更新单行考试计划。

**路径参数**: `plan_id` (int)

**请求体**:
```json
{
  "考试时间": "2024-12-15",
  "考试地点": "教室A",
  "考试方式": "笔试",
  "考试主题": "企业文化基础知识",
  "考试对象": "全体员工",
  "组织人": "张三",
  "监考人": "李四",
  "需准备资料": "试卷、答题卡",
  "备注": "无"
}
```

**响应**: 更新后的单行考试计划数据

### 7. 删除单行考试计划

**DELETE** `/row/{plan_id}`

删除单行考试计划。

**路径参数**: `plan_id` (int)

**响应**:
```json
{
  "success": true,
  "message": "删除成功"
}
```

## 数据模型

### 考试计划行字段说明

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 序号 | int | 是 | 序号（1-10） |
| 考试时间 | date | 否 | 考试时间（YYYY-MM-DD） |
| 考试地点 | string | 否 | 考试地点（最大200字符） |
| 考试方式 | string | 否 | 考试方式（最大100字符） |
| 考试主题 | string | 否 | 考试范围/主题（最大200字符） |
| 考试对象 | string | 否 | 考试对象（最大200字符） |
| 组织人 | string | 否 | 组织人（最大100字符） |
| 监考人 | string | 否 | 监考人（最大100字符） |
| 需准备资料 | string | 否 | 需准备资料（文本） |
| 备注 | string | 否 | 备注（文本） |

## 错误处理

所有 API 端点可能返回以下错误：

- `400 Bad Request`: 请求参数错误
- `404 Not Found`: 资源不存在
- `500 Internal Server Error`: 服务器内部错误

错误响应格式：
```json
{
  "detail": "错误信息"
}
```

## 注意事项

1. 每次创建或更新计划时，会先删除该校区、年份、月份的所有旧数据，然后插入新数据
2. 序号建议从1开始，连续编号
3. 日期格式使用 ISO 8601 格式（YYYY-MM-DD）
4. 所有文本字段支持中文
5. 索引已优化，查询性能良好
