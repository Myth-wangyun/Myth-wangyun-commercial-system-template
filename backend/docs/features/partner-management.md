# 合作方管理功能

## 📋 功能概述

合作方管理功能用于管理各类合作伙伴的联系信息，包括广告代理、网络服务商、招生合作伙伴等，提供完整的CRUD操作和数据管理能力。

## 🎯 主要功能

### 1. 合作方信息管理
- **信息录入**: 支持合作方基本信息录入
- **信息编辑**: 支持修改合作方信息
- **信息删除**: 支持删除合作方记录
- **信息查看**: 支持查看合作方详细信息

### 2. 分类管理
- **合作方类型**: 8种预定义的合作方类型
- **类型筛选**: 支持按类型筛选合作方
- **类型统计**: 显示各类型合作方数量统计

### 3. 搜索和筛选
- **关键词搜索**: 支持按公司名称、联系人搜索
- **类型筛选**: 支持按合作方类型筛选
- **分页显示**: 支持分页浏览合作方列表

## 📊 合作方类型

系统支持以下8种合作方类型：

1. **广告代理** - 广告代理公司
2. **网络** - 网络服务提供商
3. **平媒** - 平面媒体合作伙伴
4. **招生合作伙伴** - 招生业务合作伙伴
5. **网络服务** - 网络技术服务商
6. **人才服务** - 人力资源服务商
7. **通话服务** - 电话通信服务商
8. **物业服务** - 物业管理服务商

## 🎨 界面设计

- **操作按钮**: 每行提供查看、编辑、删除操作
- **分页控制**: 底部提供分页导航

## 📊 数据字段

### 必填字段
- **公司名称**: 合作方公司名称（最大100字符）
- **联系人**: 联系人姓名（最大50字符）
- **合作方类型**: 从预定义类型中选择

### 可选字段
- **电话**: 公司电话（最大20字符）
- **网站**: 公司网站（最大200字符）
- **地址**: 公司地址（最大200字符）
- **联系人手机**: 联系人手机号（最大20字符）
- **QQ**: QQ号码（最大20字符）
- **微信**: 微信号（最大50字符）

### 系统字段
- **合作方ID**: 自动生成的主键
- **创建时间**: 记录创建时间
- **更新时间**: 记录最后更新时间

## 📊 使用示例

1. 点击"添加合作方"按钮
2. 填写必填信息：
   - 公司名称: 北京科技有限公司
   - 联系人: 张三
   - 合作方类型: 网络服务
3. 填写可选信息：
   - 电话: 010-12345678
   - 网站: www.example.com
   - 地址: 北京市朝阳区
4. 点击"保存"按钮

### 搜索合作方
1. 在搜索框中输入关键词
2. 系统实时显示搜索结果
3. 点击搜索结果查看详情
4. 使用筛选条件进一步筛选

1. 点击合作方列表中的"编辑"按钮
2. 修改需要更新的信息
3. 点击"保存"按钮
4. 系统自动更新数据

### 删除合作方
1. 点击合作方列表中的"删除"按钮
2. 系统显示确认对话框
3. 确认删除操作
4. 系统删除记录并更新列表

## 🚨 常见问题

### 数据录入问题
**Q: 为什么不能添加重复的公司名称和联系人？**
A: 这是业务规则限制，防止重复录入相同的合作方信息。

**Q: 如何修改合作方类型？**
A: 在编辑合作方信息时，可以从下拉列表中选择新的合作方类型。

### 数据显示问题
**Q: 为什么搜索不到合作方？**
A: 检查搜索关键词是否正确，确认合作方信息已保存。

**Q: 如何查看合作方统计信息？**
A: 在合作方列表页面顶部会显示统计信息。

### 操作问题
**Q: 如何批量删除合作方？**
A: 选择多个合作方记录，点击批量删除按钮。

**Q: 如何导出合作方数据？**
A: 使用数据导出功能，支持Excel格式导出。
