# 网络投放效果汇总功能

## 功能概述

网络投放效果汇总功能是市场管理模块的一个子功能，用于展示和分析网络广告投放的详细效果数据。该功能提供按月汇总的详细表格，支持校区筛选和多种指标分析。

## 功能特点

### 1. 月度汇总展示
- 显示指定月份的所有天数（1-31日）
- 按媒体来源分类展示数据
- 支持多维度指标分析

### 2. 指标类型
- **投放金额**: 每日广告投放费用
- **展现量**: 广告展示次数
- **点击量**: 广告点击次数
- **IP**: 独立访问IP数
- **PV**: 页面浏览量
- **对话量**: 用户对话次数
- **有效对话量**: 有效对话次数
- **咨询量**: 咨询次数
- **咨询量成本**: 每个咨询的成本
- **平均点击价格**: 平均每次点击的价格
- **点击率**: 点击量与展现量的比率

### 3. 筛选功能
- **校区筛选**: 支持按校区筛选数据
- **月份导航**: 支持上一月、下一月、本月快速切换
- **月份选择**: 支持直接选择特定年月

### 4. 数据展示
- **每日数据**: 显示每日的详细指标
- **合计数据**: 显示月度汇总统计
- **媒体分类**: 按不同媒体来源分别展示
- **今日高亮**: 自动高亮显示当天日期

## 使用方法

### 1. 访问功能
1. 登录系统后，点击左侧导航栏的"市场"菜单
2. 展开市场管理子菜单
3. 点击"网络投放效果汇总"

### 2. 筛选数据
1. **选择校区**: 在"校区"下拉框中选择特定校区，或选择"===全部==="查看所有校区
2. **选择月份**: 
   - 使用"上一月"/"下一月"按钮进行月份导航
   - 直接选择月份输入框
   - 点击"本月"快速回到当前月份
3. **统计**: 点击"统计"按钮刷新数据

### 3. 查看数据
- 表格按媒体来源分组显示
- 每行显示一个指标，每列显示一天的数据
- "合计"列显示该指标的月度汇总
- 空数据或0值显示为空单元格

## 技术实现

### 后端API

#### 获取校区列表
```
GET /api/v1/market/summary/campus-list
```

#### 获取月度汇总数据
```
GET /api/v1/market/summary/monthly?年份=2025&月份=1&校区=盛邦校区
```

参数说明：
- `年份`: 统计年份（必填）
- `月份`: 统计月份，1-12（必填）
- `校区`: 校区筛选，可选

### 前端实现
- 独立的HTML页面 (`frontend/network-summary.html`)
- 响应式设计，支持移动端访问
- 实时数据加载和更新
- 友好的用户交互体验

### 数据库支持
- 基于现有的`投放明细表`
- 支持按日期和媒体来源分组查询
- 自动计算各种比率和汇总数据

## 数据来源

网络投放效果汇总功能使用现有的市场投放数据，包括：
- 日投放数据登记模块录入的数据
- 批量导入的Excel数据
- API接口提交的数据

## 注意事项

1. **数据完整性**: 确保投放数据已正确录入系统
2. **校区名称**: 校区名称应与数据录入时使用的媒体来源保持一致
3. **月份范围**: 系统会显示完整月份的所有天数，无数据的天数显示为空
4. **性能优化**: 大量数据时建议使用校区筛选功能
