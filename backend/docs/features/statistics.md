# 统计分析功能

## 📊 功能概述

统计分析功能提供多维度、多周期的数据分析和可视化，帮助用户深入了解市场投放效果，支持数据驱动的决策制定。

## 🎯 主要功能

### 1. 多维度统计
- **按日统计**: 每日投放数据统计和趋势分析
- **按周统计**: 每周数据汇总和对比分析
- **按月统计**: 每月数据统计和趋势分析
- **按年统计**: 年度数据汇总和对比分析

### 2. 数据可视化
- **趋势图表**: 消费、点击、对话等指标趋势图
- **对比图表**: 不同媒体来源效果对比
- **分布图表**: 数据分布和占比分析
- **实时更新**: 数据变化时图表实时更新

### 3. 关键指标分析
- **点击率分析**: 点击率趋势和优化建议
- **转化率分析**: 对话转化率和留电率分析
- **成本分析**: 平均点击价格和对话成本分析
- **ROI分析**: 投资回报率计算和分析

## 📈 统计维度

### 时间维度
1. **日统计**: 最近30天的每日数据
2. **周统计**: 最近12周的每周数据
3. **月统计**: 最近12个月的每月数据
4. **年统计**: 最近5年的每年数据

### 媒体维度
1. **百度**: 百度搜索广告数据
2. **360**: 360搜索广告数据
3. **搜狗**: 搜狗搜索广告数据
4. **神马**: 神马搜索广告数据
5. **其他**: 其他媒体渠道数据

### 指标维度
1. **消费指标**: 消费金额、平均消费
2. **流量指标**: 展现量、点击量、IP、PV
3. **转化指标**: 对话量、有效对话、咨询量
4. **效率指标**: 点击率、转化率、留电率

### SQL视图优化
```sql
-- 按日统计视图
CREATE OR REPLACE VIEW v_按日汇总 AS
SELECT 
    日期,
    COUNT(*) as 记录数,
    SUM(消费金额) as 总消费金额,
    SUM(展现量) as 总展现量,
    SUM(点击量) as 总点击量,
    SUM(对话量) as 总对话量,
    -- 计算关键指标
    CASE WHEN SUM(展现量) > 0 
         THEN ROUND(SUM(点击量) / SUM(展现量) * 100, 2) 
         ELSE 0 END as 点击率,
    CASE WHEN SUM(点击量) > 0 
         THEN ROUND(SUM(消费金额) / SUM(点击量), 2) 
         ELSE 0 END as 平均点击价格
FROM 投放明细表
GROUP BY 日期;
```

## 📈 统计指标详解

### 基础指标
1. **总记录数**: 统计周期内的数据记录总数
2. **总消费金额**: 统计周期内的总投放费用
3. **总展现量**: 统计周期内的总广告展现次数
4. **总点击量**: 统计周期内的总广告点击次数
5. **总对话量**: 统计周期内的总对话数量

### 计算指标
1. **点击率**: (点击量 / 展现量) × 100%
2. **对话转化率**: (对话量 / 点击量) × 100%
3. **留电率**: (咨询量 / 有效对话) × 100%
4. **平均点击价格**: 消费金额 / 点击量
5. **平均对话成本**: 消费金额 / 对话量

### 趋势指标
1. **环比增长率**: 与上一周期相比的增长率
2. **同比增长率**: 与去年同期相比的增长率
3. **累计增长率**: 累计数据的增长率
4. **移动平均**: 移动平均趋势线

## 🚨 常见问题

### 数据显示问题
**Q: 为什么图表显示空白？**
A: 检查筛选条件，确认有数据，检查网络连接。

**Q: 为什么统计数据不准确？**
A: 检查数据源，确认计算逻辑，验证数据完整性。

### 性能问题
**Q: 为什么统计查询很慢？**
A: 检查数据库性能，考虑增加筛选条件，优化查询语句。

**Q: 为什么图表加载慢？**
A: 检查数据量大小，考虑分页加载，优化图表配置。

### 功能问题
**Q: 如何导出统计数据？**
A: 使用数据导出功能，支持Excel格式导出。

**Q: 如何设置数据预警？**
A: 在系统设置中配置关键指标预警阈值。
