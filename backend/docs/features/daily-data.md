# 日投放数据登记功能

## 📊 功能概述

日投放数据登记是系统的核心功能，用于录入和管理每日的市场投放数据，包括消费金额、展现量、点击量、对话量等关键指标。

## 🎯 主要功能

### 1. 数据录入
- **单条录入**: 支持逐条录入投放数据
- **批量录入**: 支持Excel文件批量导入
- **数据验证**: 完整的数据格式和业务规则验证
- **实时保存**: 数据录入后立即保存到数据库

### 2. 数据展示
- **列表展示**: 分页显示投放数据列表
- **统计卡片**: 10个关键指标实时统计
- **筛选功能**: 支持按日期、媒体来源筛选
- **排序功能**: 支持按日期、金额等字段排序

### 3. 数据管理
- **编辑功能**: 支持修改已有数据
- **删除功能**: 支持删除错误数据
- **批量操作**: 支持批量删除和修改
- **数据导出**: 支持数据导出为Excel格式

## 📈 统计指标

### 基础指标
1. **总记录数**: 当前筛选条件下的数据记录总数
2. **总消费金额**: 所有投放的总消费金额
3. **总点击量**: 所有投放的总点击次数
4. **总对话量**: 所有投放产生的总对话数

### 扩展指标
5. **总有效对话**: 有效对话数量
6. **总PV**: 页面浏览量
7. **总咨询量**: 留点数量
8. **点击率**: 点击量/展现量 × 100%

### 转化指标
9. **对话转化率**: 对话量/点击量 × 100%
10. **留电率**: 咨询量/有效对话 × 100%
11. **平均点击价格**: 消费金额/点击量

## 🔍 数据验证

### 前端验证
```javascript
// 数据格式验证
const validateData = (data) => {
    // 日期格式验证
    if (!isValidDate(data.日期)) {
        throw new Error('日期格式不正确');
    }
    
    // 数值范围验证
    if (data.消费金额 < 0) {
        throw new Error('消费金额不能为负数');
    }
    
    // 业务规则验证
    if (data.点击量 > data.展现量) {
        throw new Error('点击量不能大于展现量');
    }
};
```

### 后端验证
```python
# Pydantic模型验证
class 日投放数据创建(BaseModel):
    日期: date = Field(..., description="投放日期")
    媒体来源: str = Field(..., max_length=50, description="媒体来源")
    消费金额: float = Field(..., ge=0, description="消费金额")
    展现量: int = Field(..., ge=0, description="展现量")
    点击量: int = Field(..., ge=0, description="点击量")
    
    @field_validator('点击量')
    def validate_clicks(cls, v, info):
        if '展现量' in info.data and v > info.data['展现量']:
            raise ValueError('点击量不能大于展现量')
        return v
```

## 🚨 常见问题

### 数据录入问题
**Q: 为什么点击量不能大于展现量？**
A: 这是业务规则限制，点击量应该小于等于展现量。

**Q: 如何批量导入数据？**
A: 使用Excel文件导入功能，支持.xlsx和.xls格式。

### 数据显示问题
**Q: 为什么统计卡片显示为0？**
A: 检查筛选条件是否正确，确认数据库中有数据。

**Q: 如何刷新统计数据？**
A: 点击"刷新"按钮或重新设置筛选条件。

### 性能问题
**Q: 数据加载很慢怎么办？**
A: 检查网络连接，确认数据库性能，考虑增加筛选条件。
