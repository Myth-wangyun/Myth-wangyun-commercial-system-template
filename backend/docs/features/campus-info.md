# 校区信息功能

## 📍 功能概述

校区信息功能用于展示和管理各校区的基本信息，包括校区名称、地址、联系方式等，为系统用户提供校区信息的统一查看入口。

## 🎯 主要功能

### 1. 校区信息展示
- **信息展示**: 展示各校区的基本信息
- **详细信息**: 显示校区的详细联系信息
- **地图定位**: 支持校区位置的地图显示
- **联系方式**: 提供校区的联系方式

### 2. 信息管理
- **信息维护**: 支持校区信息的维护和更新
- **数据同步**: 确保校区信息的准确性和时效性
- **信息验证**: 验证校区信息的完整性

## 🏢 校区信息字段

### 基本信息
- **校区名称**: 校区的正式名称
- **校区地址**: 校区的详细地址
- **联系电话**: 校区的主要联系电话
- **联系邮箱**: 校区的联系邮箱

### 扩展信息
- **校区类型**: 校区的类型分类
- **成立时间**: 校区的成立时间
- **负责人**: 校区负责人信息
- **营业时间**: 校区的营业时间

### 位置信息
- **经度**: 校区位置的经度坐标
- **纬度**: 校区位置的纬度坐标
- **交通信息**: 到达校区的交通信息
- **周边设施**: 校区周边的配套设施

## 🎨 界面设计

### 列表展示
- **卡片布局**: 使用卡片形式展示校区信息
- **网格排列**: 响应式网格布局适配不同屏幕
- **信息层次**: 清晰的信息层次和视觉重点
- **操作按钮**: 提供查看详情、编辑等操作

### 详情页面
- **完整信息**: 显示校区的完整信息
- **地图集成**: 集成地图显示校区位置
- **联系功能**: 提供直接联系功能
- **导航功能**: 提供导航到校区的功能

## 🔧 技术实现

### 后端API
```python

GET /api/v1/campus/list           # 获取校区列表
GET /api/v1/campus/{id}           # 获取校区详情
PUT /api/v1/campus/{id}           # 更新校区信息
GET /api/v1/campus/statistics     # 获取校区统计
```

### 数据库设计
```sql
-- 校区信息表
CREATE TABLE 校区信息表 (
    校区ID INT AUTO_INCREMENT PRIMARY KEY,
    校区名称 VARCHAR(100) NOT NULL,
    校区地址 VARCHAR(200) NOT NULL,
    联系电话 VARCHAR(20),
    联系邮箱 VARCHAR(100),
    校区类型 VARCHAR(50),
    成立时间 DATE,
    负责人 VARCHAR(50),
    营业时间 VARCHAR(100),
    经度 DECIMAL(10, 6),
    纬度 DECIMAL(10, 6),
    交通信息 TEXT,
    周边设施 TEXT,
    创建时间 DATETIME DEFAULT CURRENT_TIMESTAMP,
    更新时间 DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

## 🚨 常见问题

### 显示问题
**Q: 为什么校区信息不显示？**
A: 检查数据库连接，确认校区信息已录入。

**Q: 为什么地图不显示？**
A: 检查地图API配置，确认网络连接正常。

### 功能问题
**Q: 如何添加新校区？**
A: 使用校区管理功能添加新校区信息。

**Q: 如何更新校区信息？**
A: 在校区详情页面点击编辑按钮更新信息。

### 地图问题
**Q: 为什么地图标记位置不准确？**
A: 检查校区的经纬度坐标是否正确。

**Q: 如何设置地图中心点？**
A: 在系统配置中设置默认地图中心点。
