# 校区历史数据生成器

这个目录包含了用于生成7个校区历史数据的Puppeteer自动化脚本。

## 文件说明

- `quick-campus-data-generator.js` - 快速生成脚本（推荐使用）
- `generate-campus-historical-data.test.js` - 完整测试脚本
- `package.json` - 依赖管理文件

## 快速开始

### 1. 安装依赖

```bash
cd test/puppeteer
npm install
```

### 2. 确保后端服务运行

确保后端服务器在 `http://localhost:8000` 运行，并且数据库已初始化。

### 3. 运行数据生成

```bash
# 快速生成（每月3-5条记录，2020-2025年）
npm run generate

# 或者直接运行
node quick-campus-data-generator.js
```

### 数据字段

- 点击量：基于展现量和点击率计算

- 有效对话：基于对话量计算

## 脚本特点

1. **自动登录**：使用admin账户自动登录获取token
2. **校区感知**：通过X-Campus头部为每个校区生成独立数据
3. **随机数据**：生成符合业务逻辑的随机数据
4. **进度显示**：实时显示生成进度
5. **错误处理**：记录失败的数据并继续执行
6. **数据验证**：生成完成后验证数据插入结果

## 预期结果

每个校区大约会生成：
- 时间跨度：6年（2020-2025）
- 每月记录：3-5条
- 总记录数：约216-360条/校区
- 7个校区总计：约1,500-2,500条记录

## 注意事项

1. 确保后端服务正常运行
2. 确保数据库已正确初始化
3. 生成过程可能需要几分钟时间
4. 如果生成失败，可以重新运行脚本
5. 脚本会自动跳过已存在的数据（如果API支持）

## 故障排除

如果遇到问题：

1. 检查后端服务是否运行：`curl http://localhost:8000/health`
2. 检查数据库连接
3. 查看控制台错误信息
4. 确保admin账户密码正确（默认：admin123）
