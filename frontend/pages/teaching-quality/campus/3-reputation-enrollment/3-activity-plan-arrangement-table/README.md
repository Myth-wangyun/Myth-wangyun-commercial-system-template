# 020 XX校区教质部活动计划安排表

## 功能概述

本模块实现了校区教质部活动计划安排表功能，提供两个 Tab 视图：

1. **XX校区活动计划安排表**：全校区级别的活动计划
2. **XX班级活动计划安排表**：针对具体班级的活动计划

## 核心功能

### 1. 两个 Tab 视图

#### Tab 1: XX校区活动计划安排表

- 针对整个校区的活动计划
- 校区、年份、月份筛选
- 适用于全校性活动、讲座、大型活动等

#### Tab 2: XX班级活动计划安排表

- 针对具体班级的活动计划
- 校区、班级、年份、月份筛选
- 适用于班会、班级团建、主题活动等

### 2. 数据字段

每个活动计划包含以下8个字段：

| 字段       | 说明                    | 是否必填 |
| ---------- | ----------------------- | -------- |
| 时间       | 活动时间（日期+时间段） | ✅       |
| 地点       | 活动地点                | ✅       |
| 活动形式   | 活动的形式类型          | ✅       |
| 主要内容   | 活动的详细内容描述      | ✅       |
| 负责人     | 活动负责人姓名          | ✅       |
| 预期结果   | 预期达到的效果          | -        |
| 过程关键点 | 活动过程中的关键环节    | -        |
| 实标结果   | 活动结束后的实际效果    | -        |

### 3. 数据管理功能

- **添加**：添加新的活动计划
- **编辑**：
  - 模态框编辑（点击编辑按钮）
  - 表内编辑（开启编辑模式后直接修改）
- **删除**：删除指定的活动计划
- **保存**：保存所有修改
- **刷新**：重新加载数据
- **导出**：导出活动计划表（开发中）

### 4. 筛选功能

#### 校区活动表

- 校区选择
- 年份选择（2023-2025）
- 月份选择（1-12月）

#### 班级活动表

- 校区选择
- 班级选择
- 年份选择（2023-2025）
- 月份选择（1-12月）

## 数据结构

### ActivityPlanRecord

```typescript
interface ActivityPlanRecord {
  key: string
  time: string // 时间
  location: string // 地点
  activityForm: string // 活动形式
  mainContent: string // 主要内容
  responsible: string // 负责人
  expectedResult: string // 预期结果
  processKeyPoints: string // 过程关键点
  actualResult: string // 实标结果
}
```

## 主要功能实现

### 1. Tab 切换

使用 Ant Design 的 `Tabs` 组件实现两个视图的切换：

- 校区活动计划表
- 班级活动计划表

### 2. 双模式编辑

#### 模态框编辑

- 点击"编辑"按钮打开模态框
- 表单验证（时间、地点、活动形式、主要内容、负责人为必填）
- 提交后更新数据

#### 表内编辑

- 点击"编辑"按钮进入编辑模式
- 单元格变为可编辑状态
- 支持 Input 和 TextArea 两种输入方式
- 点击"保存"按钮保存修改

### 3. 数据验证

- 时间格式验证
- 必填字段验证
- 内容长度限制

## 使用说明

### 校区活动计划表

1. **查看活动**
   - 选择校区、年份、月份
   - 查看该月的活动计划

2. **添加活动**
   - 点击"添加"按钮
   - 填写活动信息
   - 点击"确定"保存

3. **编辑活动**
   - 方式一：点击"编辑"按钮进入编辑模式，直接在表格中修改
   - 方式二：点击行操作中的"编辑"按钮，在模态框中修改

4. **删除活动**
   - 点击行操作中的"删除"按钮
   - 确认删除

### 班级活动计划表

1. **选择班级**
   - 先选择校区
   - 再选择具体班级
   - 选择年份和月份

2. **管理活动**
   - 操作方式与校区活动表相同
   - 支持添加、编辑、删除
