#### 班级名称 (className)

- `J202402`

#### 课程名称 (courseName)
- `PS`
- `Java基础`
- `UI设计基础`
- `毕业强化`

#### 教员姓名 (instructorName)
- `杜鹏涛`
- `李老师`
- `王老师`
- `张老师`

#### 首考日期 (firstExamDate)
- **格式**: `YYYY-MM-DD`
- **范围**: 
  - 2024-01-01 至 2024-12-31
  - 2025-01-01 至 2025-12-31
- **生成规则**: 每个月的每一天（根据月份实际天数）

#### 补考日期 (makeupExamDate)
- **格式**: `YYYY-MM-DD`
- **计算规则**: 首考日期 + 7天
- **示例**: 
  - 首考 `2024-01-01` → 补考 `2024-01-08`
  - 首考 `2024-12-25` → 补考 `2025-01-01`（跨年）

#### 学生成绩字段

**学号 (studentId)**
- **格式**: `TEST_{year}_{month}_{day}_{index}`
- **示例**: `TEST_2024_01_15_1`, `TEST_2024_12_31_10`

**学生姓名 (studentName)**
- **格式**: `测试学生{index}`
- **示例**: `测试学生1`, `测试学生150`

**单词成绩 (vocabularyScore)**
- **范围**: 0-100
- **适用专业**: IT类专业（Java开发、Python开发、Web前端）
- **生成规则**: 60 + (studentIndex % 40)，即 60-99分

**笔试成绩 (writtenScore)**
- **范围**: 0-100
- **适用专业**: 所有专业
- **生成规则**: 60 + (studentIndex % 40)，即 60-99分

**上机成绩 (labScore)**
- **范围**: 0-100
- **适用专业**: 所有专业
- **生成规则**: 60 + (studentIndex % 40)，即 60-99分

**平时成绩 (dailyScore)**
- **范围**: 0-100
- **适用专业**: 设计类专业（数字媒体、UI设计）
- **生成规则**: 60 + (studentIndex % 40)，即 60-99分

- **教员1评分 (instructor1Score)**: 0-100分

- 基础分数: 60 + (studentIndex % 40)，即 60-99分
- 项目加成: 项目序号 × 3分
- 平均分: (instructor1 + instructor2 + instructor3 + homeroom1 + homeroom2) / 5

## 🔍 数据查询示例

### 查询特定年份的数据
```typescript
// 查询2024年的所有考试数据
const result = await classExamScoreService.getList({}, '盛邦校区')
const data2024 = result.list.filter(r => r.firstExamDate?.startsWith('2024'))
```

### 查询特定月份的数据
```typescript
// 查询2024年1月的数据
const result = await classExamScoreService.getList({}, '盛邦校区')
const data2024_01 = result.list.filter(r => 
  r.firstExamDate?.startsWith('2024-01')
)
```

### 查询特定日期的数据
```typescript
// 查询2024年1月15日的数据
const result = await classExamScoreService.getList({}, '盛邦校区')
const data2024_01_15 = result.list.filter(r => 
  r.firstExamDate === '2024-01-15'
)
```

## ⚠️ 重要提示

1. **数据不会自动删除**: 所有测试数据会保留在数据库中
2. **数据量较大**: 预计生成数千条记录，运行时间可能需要几分钟
3. **依赖关系**: 这些数据可以被其他表格引用（如教员功能分析表）
4. **清理时机**: 在所有相关测试完成后，再统一手动清理
